# Stuff I Made

A personal creative sandbox for small web experiments, visuals, media tests, and early portfolio ideas.

## Overview

This repo is a collection space rather than a single finished product. It can be useful as an archive of creative experiments, but it should not be treated as one of the main pinned portfolio projects unless it is cleaned into a focused showcase.

## Portfolio Recommendation

For a curated public GitHub profile, stronger projects like `uwupon`, `Drift`, and `b2b-data-bot` should be prioritized above this repo.
